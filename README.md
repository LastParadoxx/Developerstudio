## ⚡ **Welcome to the Future of Code Execution**

Developer Studio v2.0 is a **futuristic, web-based code execution platform** with a sleek cyberpunk aesthetic. Write, execute, and share code across multiple programming languages with real-time output and a stunning neon-powered UI.

### 🌟 **Key Features**

- **🎨 Futuristic UI Design** - Cyberpunk-inspired interface with neon glows and animations
- **💻 Multi-Language Support** - Execute code in JavaScript, Python, C++, Java, and more
- **⚡ Real-Time Execution** - Instant code execution with live output
- **🌙 Theme Support** - Dynamic light/dark mode with animated transitions
- **💾 Save & Share** - Save code snippets and share with unique IDs
- **📱 Responsive Design** - Works seamlessly on desktop and mobile devices
- **🔧 Monaco Editor** - Professional code editing with syntax highlighting
- **📊 Error Handling** - Comprehensive error reporting and debugging

### 🛠️ **Technology Stack**

#### **Frontend**
- **React 18.2.0** - Modern UI framework
- **Vite 4.3.9** - Lightning-fast build tool
- **Monaco Editor** - VS Code-powered code editor
- **Axios** - HTTP client for API calls
- **CSS3** - Advanced animations and glassmorphism effects

#### **Backend**
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **Piston API** - Code execution engine
- **CORS** - Cross-origin resource sharing
- **Nanoid** - Unique ID generation

### 🚀 **Quick Start**

#### **Prerequisites**
- Node.js 16+ installed
- npm or yarn package manager

#### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/LastParadoxx/Developerstudio.git
   cd Developerstudio
   ```

2. **Install server dependencies**
   ```bash
   cd server
   npm install
   ```

3. **Install client dependencies**
   ```bash
   cd ../client
   npm install
   ```

4. **Start the development servers**

   **Terminal 1 - Backend Server:**
   ```bash
   cd server
   npm run dev
   ```

   **Terminal 2 - Frontend Client:**
   ```bash
   cd client
   npm run dev
   ```

5. **Open your browser**
   - Frontend: `http://localhost:5173`
   - Backend API: `http://localhost:3001`

### 🎮 **Usage**

1. **Select Language** - Choose from the dropdown menu
2. **Write Code** - Use the Monaco editor with syntax highlighting
3. **Execute** - Click the "▶ RUN CODE" button
4. **View Output** - See results in the futuristic output panel
5. **Save & Share** - Save your snippets and share the unique ID
6. **Download** - Export your code as a file

### 🔧 **API Endpoints**

- `GET /api/languages` - Get supported programming languages
- `POST /api/run` - Execute code and return output
- `POST /api/snippets` - Save a code snippet
- `GET /api/snippets/:id` - Load a saved snippet
